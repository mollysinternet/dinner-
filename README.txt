DINNER? — Vintage Cookbook Edition (V2)

Open index.html in your browser to try the website. Keep index.html, style.css and script.js together. To publish, upload these three files to your GitHub Pages repository.

This version updates the name, title, homepage, and footer. It retains the Weekly Spread, Recipe Archive, Market, Fridge Notes and Ledger. Changes save in this browser via localStorage (same key as Kitchen Board V1, to preserve data if hosted at the same origin).

This is not yet connected to Supabase. Browser data does not automatically sync between devices, and opening as a local file may use a different storage context from your hosted website.
